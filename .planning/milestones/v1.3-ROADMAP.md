**Details:**
**Success Criteria** (what must be TRUE):
  1. Approving a BUY recommendation calls `equity_buy_limit` with price as a formatted string (not a raw float) when USE_LIMIT_BUY=true

## Milestone Summary

**Decimal Phases:**

- Phase 14.1: SPY 1-year trend signal (inserted after Phase 14 — signal quality improvement, two temporal SPY perspectives)

**Key Decisions:**

- `/history` query is sell-side-only SELECT (`WHERE side='sell' AND cost_basis IS NOT NULL`) — no JOIN to avoid cartesian duplicates on multi-trade tickers
- `equity_buy_limit` price must be a formatted string `f"{price:.2f}"` — raw float triggers DeprecationWarning, future TypeError
- Limit order duration defaults to GTC (not DAY) — DAY + late approval = silent unfill that locks DB recommendation
- `USE_LIMIT_BUY` uses `.lower() == "true"` Config pattern — `bool("false")` is `True` in Python
- Earnings date sourced from `info["earningsTimestamp"]` (already fetched) — zero extra network cost
- `ticker.quarterly_income_stmt` (not `ticker.quarterly_earnings`) for EPS trend — `quarterly_earnings` returns None silently in yfinance 1.2.0
- Embed builder receives pre-formatted `earnings_date` string; all N/A/⚠️ logic in main.py (pure renderer pattern)
- Parse errors now converge on the fallback chain (reversed 2026-06-06) — Gemini free model returns unparseable output
